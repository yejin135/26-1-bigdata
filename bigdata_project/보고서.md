# [서울시 자치구별 전세가율 및 보증사고 위험도 분석 대시보드]

- 현예진 / 20241512
- **데이터 출처 / 라이선스**: 주택도시보증공사(HUG) 보증사고 데이터 및 한국부동산원(https://www.rtech.or.kr/portal/rental/rentalMarket.do)

## 1. 문제 정의
- **무엇을, 왜 분석하는가**: 최근 전세 사기 및 역전세난이 심화됨에 따라 세입자의 주거 안정성을 위협하는 '깡통전세' 위험이 커지고 있습니다. 이에 따라 서울시 25개 자치구별로 매달 변화하는 전세가율과 전세보증사고 발생 건수를 시계열로 통합 분석하여, 지역별 전세 시장의 위험도를 직관적으로 모니터링할 필요가 있습니다.
- **이 데이터로 풀고 싶은 문제 / 예측 대상(target)**: 파편화된 월별 실거래 데이터를 정제하여 자치구별 전세가율 시계열 트렌드를 도출하고, 전세가율이 높은 지역이 실제 보증사고로 이어지는지 여부를 시각화하여 위험 지역을 사전에 식별합니다. (Target: 자치구별 전세가율 및 보증사고 건수)

## 2. 데이터 소개 & EDA
- **데이터 규모(행·열), 형식**: Excel(.xlsx) 형태의 월별 파일 다수 (25개 자치구 데이터 통합), 주요 컬럼: 자치구, 년월, 평균전세가, 평균매매가, 전세가율, 보증사고건수.
- **EDA로 발견한 사실 2~3가지**:
  1. 전세가율은 특정 상수가 아닌 매달 시장 상황에 따라 유동적으로 변하며, 일부 자치구(외곽 지역)에서 중심지보다 전세가율이 높게 형성되는 양극화 현상이 관찰됨.
  2. 전세가율이 임계치를 넘은 자치구에서 시차를 두고 보증사고 발생 건수가 상승하는 패턴이 확인됨.
- **결측·이상치 처리 방법**:
  - 파일별로 상이한 자치구 명칭을 표준화하고 공백을 제거함.
  - 전세가율 데이터가 누락된 경우, 원본의 매매가/전세가 데이터를 활용해 직접 연산하여 결측치를 복구함.
  - 시계열 데이터를 병합할 때 특정 값으로 고정되는 현상(ffill/bfill의 오남용)을 방지하기 위해 자치구별, 날짜별로 독립된 정제 파이프라인을 구축함.

## 3. 특성 엔지니어링
- **새로 만든 특성과 그 근거**:
  - **동적 전세가율 연산 필드**: 원본에 전세가율이 없는 경우 `(평균전세가 / 평균매매가) * 100`을 통해 도출하여 데이터의 완전성을 확보함.
  - **시계열 정렬 키(`년월`)**: 파일명에서 숫자 패턴을 추출하여 정수형 6자리 코드로 변환함으로써, 연도별·월별 시계열 분석이 가능하도록 전처리함.

## 4. 모델 / 서비스
- **사용한 방법**: 규칙 기반 데이터 엔지니어링 파이프라인(Rule-based Data Pipeline) 및 Streamlit 대화형 시각화.
- **입력 → 출력 흐름**: `data/임대시장데이터` (RAW) → `데이터_병합.py` (ETL) → `seoul_market_preprocessed.xlsx` (Master) → `🏠_메인_화면.py` (Dashboard).
- **결과 해석**: 데이터 병합 파이프라인을 통해 각 자치구의 실질적인 전세가율 변화를 도출하였으며, 메인 대시보드를 통해 현재 서울에서 전세가율이 가장 높은 위험 지역과 보증사고 건수를 최신순으로 즉각 모니터링함.

## 5. Streamlit 앱
- **페이지 구성**:
    - **`🏠_메인_화면.py`**: 전체 현황 요약 및 전세가율 최고/최저 자치구 지표 표시.
    - **`01_🎯_기본_데이터_분석.py`**: 시장 데이터 기초 통계 및 분포 탐색.
    - **`02_📊_실거래가_정밀_분석.py`**: 자치구별 시계열 트렌드 및 보증사고 추이 비교 분석.
    - **`03_🤖_모델_서비스.py`**: 데이터 기반 진단 및 정보 제공.
- **실행 방법**:
  1. `pip install -r requirements.txt`
  2. `python data/데이터_병합.py` (마스터 데이터 생성)
  3. `streamlit run 🏠_메인_화면.py` (대시보드 실행)

## 6. 결론 & 한계
- **알게 된 것**: 데이터 분석에서 가장 큰 비중은 모델링이 아닌 '데이터 전처리'라는 점을 배웠으며, 파편화된 공공데이터를 일관성 있게 병합하는 과정에서 시스템의 무결성을 확보하는 것이 얼마나 중요한지 깨달음.
- **아쉬운 점 / 더 했다면 할 것**: 현재 기술 통계 분석에 머물러 있으나, 향후 시계열 예측 모델(LSTM 등)을 추가 도입하여 위험 자치구를 사전에 경고하는 '전세 리스크 예보 시스템'으로 발전시킬 계획임.
