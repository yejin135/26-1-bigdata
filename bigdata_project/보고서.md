# 공공 임대차 데이터 기반 서울시 자치구별 전세 보증사고 위험 등급 예측 대시보드

- **이름 / 학번**: 현예진 / 2024151
- **데이터 출처 / 라이선스**: 한국부동산원 임대차시장 사이렌 (https://www.rtech.or.kr/portal/rental/rentalMarket.do) / 공공데이터 자유이용

## 1. 문제 정의

전세 사기 및 깡통전세는 최근 대한민국에서 심각한 사회 문제로 대두되고 있으며, 피해의 절대다수가 연립·다세대 주택에서 발생하고 있다. 아파트와 달리 연립·다세대는 거래가 적고 가격이 불투명하여 매매가 대비 전세가 비율(전세가율)이 비정상적으로 높아지는 구조적 취약점을 가진다. 전세가율이 80%를 초과하면 경매 시 세입자가 보증금을 온전히 돌려받지 못하는 소위 깡통전세 상태가 된다.

본 프로젝트는 서울시 25개 자치구의 연립·다세대 주택 전세가율 및 HUG 보증사고 데이터를 결합하여, **현재 시점($t$)의 전세 시장 지표로 다음 달($t+1$)의 보증사고 위험 등급(상/중/하)을 선제적으로 예측**하고 Streamlit 대시보드로 시각화하는 것을 목표로 한다.

- **예측 대상(Target):** $t+1$ 시점 자치구별 보증사고건수를 전체 분포 기준 3분위로 분류한 위험 등급 (상/중/하)

## 2. 데이터 소개 & EDA

### 데이터 규모 및 형식
- **원본:** 한국부동산원 임대차시장 사이렌 월별 xlsx 파일 46개 (2022년 8월 ~ 2026년 5월)
- **병합 후:** 1,150행 × 7열 (서울시 25개 자치구 × 46개월)
- **전처리 후:** 1,150행 × 13열 (파생 피처 및 타깃 변수 추가)
- **주요 컬럼:** `년월`, `자치구`, `전세가율(%)`, `전세가율_3개월(%)`, `보증사고건수`, `보증사고금액`, `보증사고율(%)`

### EDA에서 발견한 사실

**① 강서구의 압도적 피해 집중**

누적 보증사고 건수 기준 Top 5를 분석한 결과, 강서구가 전체 기간 동안 가장 많은 보증사고가 발생한 자치구로 나타났다. 강서구는 전세가율도 분석 기간 중 80%를 지속적으로 상회하여 전세가율과 보증사고 건수의 연관성을 단적으로 보여주는 사례다.

**② 전세가율 80% 기준으로 보증사고율이 2.4배 차이**

전세가율 80% 이상 집단의 평균 보증사고율은 9.96%로, 80% 미만 집단(4.08%)보다 약 2.4배 높게 나타났다. Welch t-검정 결과 이 차이는 통계적으로 매우 유의미하였다 (t = 8.50, p < 0.0001).

**③ 전세가율 상승이 보증사고에 선행**

시차(lag) 분석 결과, 이번 달 전세가율은 6개월 뒤 보증사고와 가장 높은 상관관계를 보였다. 이는 전세 계약 기간(2년) 특성상 전세가율 급등 이후 계약 만료 시점에 사고가 집중되는 현실을 반영한다. 다만 본 서비스의 조기 경보 목적에 맞춰 최소 시차인 1개월($t+1$)을 예측 타깃으로 설정하였으며, lag=1에서도 통계적으로 유의한 양의 상관관계(r = 0.455, p < 0.05)가 확인되었다.

### 결측·이상치 처리

- **전세가율 NaN:** 거래가 부족하여 산정 불가능한 달에 발생. 자치구별 인접 월 선형 보간(interpolation)으로 처리
- **보증사고율 NaN:** 사고가 없는 달로 판단하여 0으로 대체
- **타깃 NaN:** 마지막 달(2026년 5월)은 다음 달 데이터가 존재하지 않아 모델 학습에서 자동 제외 (25행)

## 3. 특성 엔지니어링

원본 데이터의 전세가율만으로는 현재 수치가 높은지 낮아지고 있는지 알 수 없다. 이를 보완하기 위해 시계열 특성을 반영한 3가지 파생 피처를 생성하였다.

| 파생 피처 | 계산 방법 | 생성 근거 |
| :--- | :--- | :--- |
| `전세가율_변화율` | 이번 달 전세가율 − 지난달 전세가율 | 단순 수치보다 "얼마나 올랐는가"가 위험 신호. 전세가율이 급등하는 지역을 포착 |
| `이동평균_전세가율` | 자치구별 최근 3개월 이동평균 | 한 달 노이즈를 제거하고 실제 추세 파악. 일시적 변동에 모델이 흔들리지 않도록 안정화 |
| `전세가율_가속도` | 변화율의 변화 (변화율 − 전월 변화율) | "점점 빠르게 오르는" 구간 감지. 단순 상승보다 가속 상승이 더 위험한 신호 |

## 4. 모델 / 서비스

### 사용한 방법
**RandomForestClassifier** (Scikit-learn)를 사용하여 $t+1$ 위험 등급(상/중/하)을 분류하였다.

회귀(Regressor) 대신 분류(Classifier)를 선택한 이유는 다음과 같다.
- 1,150행의 제한된 데이터에서 연속형 수치 예측은 노이즈에 취약
- 상/중/하 3등급으로 구간화하면 일시적 수치 변동을 흡수하여 안정적인 예측 가능
- 세입자에게 직관적인 위험 등급을 제공하는 것이 실용적

### 입력 → 출력 흐름

```
[입력 - t 시점]                    [출력 - t+1 시점 예측]
전세가율           ┐
전세가율_변화율    │  RandomForest   →   위험 등급 (상/중/하)
이동평균_전세가율  │  Classifier         + 각 등급 확률
전세가율_가속도    │
보증사고건수       ┘
```

### 학습 / 검증 분리

시간 기반 분리를 적용하여 미래 데이터가 학습에 포함되는 데이터 누수를 방지하였다.
- **학습:** 2022년 9월 ~ 2026년 1월
- **검증:** 2026년 2월 ~ 2026년 4월 (마지막 3개월)

### 성능 지표

| 지표 | 값 |
| :--- | :--- |
| 정확도 (Accuracy) | 72.0% |
| F1-Score (macro) | 0.640 |
| 고위험 → 안전 오판 | **0건** |
| 안전 → 고위험 오판 | **0건** |

전체 정확도는 72%이며, 모든 오분류는 인접 등급(상↔중, 중↔하) 사이에서만 발생하였다. 고위험 지역을 안전으로, 또는 안전 지역을 고위험으로 극단적으로 오판하는 경우는 단 한 건도 없었다. 전세 사기 조기경보 시스템 특성상 이 점이 가장 중요한 성능 기준이다.

## 6. 결론 & 한계

### 알게 된 것

- 전세가율과 보증사고율 사이에는 통계적으로 유의미한 양의 상관관계가 존재한다 (r = 0.455, p < 0.05).
- 전세가율 80% 기준으로 보증사고율이 통계적으로 유의미하게 달라진다 (p < 0.0001). 80%는 단순한 관행적 기준이 아닌 실제 데이터로 입증된 임계점이다.
- 전세가율 상승은 6개월 뒤 보증사고와 가장 높은 상관을 보이며, 이는 전세 계약 만료 시점에 사고가 집중되는 현실을 반영한다.
- RandomForestClassifier로 t+1 위험 등급을 72% 정확도로 예측할 수 있으며, 극단적 오판(고위험↔안전)은 발생하지 않았다.

### 아쉬운 점 / 향후 과제

- **데이터 한계:** 현재 전세가율과 보증사고 데이터만 사용하였으나, 금리, 매매 거래량, 미분양 현황 등 거시경제 변수를 추가하면 예측 정확도가 향상될 것으로 기대된다.
- **시차 불일치:** 통계적으로는 6개월 시차에서 상관이 최대이나, 서비스 실용성을 위해 1개월 시차를 선택하였다. 향후 2~6개월 다중 시차 예측 기능을 추가하면 더 완성도 높은 서비스가 될 것이다.
- **지도 시각화 미구현:** 계획 단계에서는 Folium을 이용한 서울시 자치구 choropleth 지도를 구현하려 하였으나, 데이터 파이프라인 안정화에 집중하여 이번 버전에서는 제외하였다. 향후 구현 시 위험 등급을 지도 위에 색상으로 표현하면 직관성이 크게 향상될 것이다.
- **모델 개선:** 현재 RandomForestClassifier의 F1이 0.640 수준이다. XGBoost나 LightGBM 등 부스팅 계열 모델을 추가로 비교하거나, 하이퍼파라미터 튜닝을 적용하면 성능 향상 가능성이 있다.
