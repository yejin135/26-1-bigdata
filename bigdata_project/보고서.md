# 빅데이터 프로젝트 계획서 

## 프로젝트 주제

공공데이터 기반 서울시 구별 전세 사기 위험도 지수 산출 및 위험 구역 예측
 
> 최근 사회적 문제로 대두된 전세 사기를 공공데이터(CSV)로 분석하여,
> 서울시 행정구별 임차인 위험도 지수를 산출하고 GIS 시각화를 통해 위험 지역을 직관적으로 표현하는 초압축형 프로젝트
 
---

# 프로젝트 문제정의

## 1. 선택한 데이터

### 데이터 1: 한국부동산원 - 전국주택가격동향조사 월별동향 아파트 평균 매매가격 대비 전세가격 (전세가율)
- **이름 / 출처(URL) / 라이선스:** 한국부동산원 전국주택가격동향조사 / 공공데이터포털 (https://www.data.go.kr/data/15143750/fileData.do) / 공공데이터 한시적 이용약관
- **크기 / 형식:** 약 300행 × 15열 내외 (서울특별시 25개 자치구 필터링 기준) / CSV 형식
- **어떻게 받았나:** 웹사이트에서 직접 CSV 파일로 다운로드

### 데이터 2: 주택도시보증공사(HUG) - 지역별 전세금반환보증 사고현황
- **이름 / 출처(URL) / 라이선스:** 주택도시보증공사 지역별 전세금반환보증 사고현황 / 공공데이터포털 (https://www.data.go.kr/data/15134221/fileData.do?recommendDataYn=Y) / 공공데이터 한시적 이용약관
- **크기 / 형식:** 약 100행 × 10열 내외 (서울특별시 행정구역 필터링 기준) / CSV 형식
- **어떻게 받았나:** 웹사이트에서 직접 CSV 파일로 다운로드

## 2. 풀고 싶은 문제
- **한 문장으로:** "**공공 통계** 데이터로 **서울시 자치구별 전세 사기 위험도 점수**를 **예측 및 시각화**하고 싶다." 
- **예측/분류 대상이 있나? 있으면 무엇:** - **예측 대상(Target):** 행정구역(구)별 임차인 위험도 점수 (연속형 변수 예측, Regression) 
  - *설명:* 선행 리스크 지표인 '전세가율'과 실제 리스크 발현 지표인 '보증사고율'을 가중합산하여 산출한 고유의 위험도 점수(0~100점)를 Target 컬럼으로 정의하고 이를 예측함

---

## 3. 만들 서비스(완성 모습)
- **사용자가 무엇을 입력하면 → 무엇을 보여주는 앱인가:** - **사용자 입력:** 사용자가 Streamlit 웹 화면에서 관심을 두고 있는 **서울특별시 내 특정 자치구(예: 강서구, 관악구 등)**를 선택 및 입력 
  - **서비스 출력:** 머신러닝 모델을 통해 예측된 해당 자치구의 **단기 전세 위험도 등급(상/중/하)**을 보여주고, Plotly 인터랙티브 그래프 및 Folium 지도를 연동하여 서울시 전체의 위험 구역 현황을 직관적 대시보드로 표출하는 멀티페이지형 Streamlit 웹 애플리케이션
- **사용할 기술:** ML (scikit-learn 라이브러리의 **Random Forest Regressor** 분류·회귀 알고리즘 적용)

---

## 4. 예상 난관 1가지
- **내용:** Streamlit 멀티페이지 구조에서 사용자의 조작이나 화면 새로고침 발생 시, 매번 대용량 CSV 데이터를 다시 로드하게 되어 웹 앱의 반응 속도가 급격히 저하되는 현상
- **해결책:** 가이드라인의 성능 최적화 지침에 따라, `src/data_loader.py` 스크립트에 데이터 로딩 함수를 격리하고 상단에 **`@st.cache_data` 데코레이터를 필수 적용**함. 이를 통해 최초 1회만 데이터를 메모리에 적재하고 이후에는 캐싱된 데이터를 활용하도록 설계하여 시스템 부하를 최소화하고 안정적인 MVP 서비스를 구동할 예정임

## 데이터 (수집 방식 변경: API → CSV 통계 데이터)

### 1. 한국부동산원 — 행정구역별 전세가율 현황 (KOSIS / 공공데이터포털)
- **출처:** 국가통계포털(KOSIS) 또는 공공데이터포털
- url: https://www.data.go.kr/data/15143750/fileData.do
- **활용:** 서울시 25개 구별 월별/분기별 전세가율($\text{전세가} \div \text{매매가}$) 추출 → 데이터 정제 및 결합의 핵심 변수
- **형식:** CSV 파일 (다운로드 후 즉시 활용)

### 2. 주택도시보증공사(HUG) — 전세보증금 반환보증 사고현황 (지역별)
- **출처:** 공공데이터포털
- url: https://www.data.go.kr/data/15134221/fileData.do?recommendDataYn=Y
- **활용:** 서울시 구별 보증 발급건수 및 사고율 추출 → 위험도 지수 산출 및 회귀 모델의 주요 독립변수(X)로 활용
- **형식:** CSV 파일 (기존 계획 데이터 유지)

## 핵심 목표 및 기대효과 (MVP 기준 정의)
- **1_EDA.py (1차 작업):** pandas를 활용하여 서울시 25개 구 데이터 요약, 결측치 처리 및 전세가율 기본 분포 확인
- **2_시각화.py (2차 작업):** `Plotly`를 이용하여 전세가율과 보증사고율 간의 상관관계 및 인사이트를 보여주는 인터랙티브 그래프 구현 (2개 이상)
- **3_모델_서비스.py (3차 작업):** `scikit-learn (Random Forest)` 기반 회귀 모델을 탑재하여, 사용자가 구를 입력하면 단기 위험도 예측 결과를 Folium Choropleth 지도와 함께 화면에 표출하는 MVP(최소 기능 제품) 서비스 완성
