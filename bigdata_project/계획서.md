# 📄 빅데이터 프로젝트 계획서

## 1. 프로젝트 주제
### **최신 공공 실거래 데이터 기반 서울시 자치구별 단기 전세 리스크(보증사고) 예측 및 등급화 대시보드**

> 최근 사회적 문제로 대두된 전세 사기 및 깡통전세 리스크를 서울시 자치구별 최신 1년 치 시계열 실거래 및 보증사고 데이터를 결합하여 분석합니다. 현재 시점의 시장 지표를 통해 다음 달의 위험 수치를 연속형으로 예측(Regression)하고, 이를 직관적인 위험 등급(상/중/하)으로 변환하여 지도로 시각화하는 Streamlit 기반의 초압축형 고도화 프로젝트입니다.

---

## 2. 프로젝트 문제 정의

### 2.1 선택한 데이터셋
* **데이터 1: 서울시 자치구별 실거래가 기반 전세가율 데이터**
  * **출처(URL):** https://land.seoul.go.kr/land/rtms/transactionInfo.do
  * **형식 및 크기:** CSV/Excel 형식, 서울시 25개 자치구의 12개월 분량 (2025년 5월 ~ 2026년 4월 연속 패널 데이터)
  * **주요 변수:** `자치구명`, `기준년월`, `평균 매매가격`, `평균 전세가격`, `전세가율(전세가/매매가)`
* **데이터 2: 한국부동산원 임대차시장 사이렌 - 자치구별 전세보증사고 현황**
  * **출처(URL):** https://www.rtech.or.kr/portal/rental/rentalMarket.do
  * **형식 및 크기:** CSV/Excel 형식, 서울시 25개 자치구의 12개월 분량 (2025년 5월 ~ 2026년 4월 동기화 데이터)
  * **주요 변수:** `자치구명`, `기준년월`, `보증사고 건수`, `보증사고 금액`, `사고율`

### 2.2 풀고 싶은 문제 
* **핵심 목표:** "현재 달($t$)의 미시적 전세 시장 지표를 통해 **다음 달($t+1$) 해당 자치구의 실제 보증사고 발생 위험 수치**를 선제적으로 예측하고 시각화한다."
* **예측 대상 (Target 컬럼):** 다음 달($t+1$) 자치구별 실제 보증사고 건수 또는 사고율 (연속형 변수 예측, **Regression**)
* **시차 설계 (Time-lag Model):** * 원인 지표(독립변수 $X$): $t$ 시점의 자치구별 전세가율, 실거래 변동성
  * 결과 지표(종속변수 $Y$): $t+1$ 시점의 자치구별 보증사고 건수 (`df.groupby('자치구')['사고건수'].shift(-1)`)

## 3. 만들 서비스 (완성 모습)

### 3.1 서비스 메커니즘 (사용자 시나리오)
* **사용자 입력:** Streamlit 웹 화면의 사이드바에서 관심 있는 **서울특별시 내 자치구(예: 강서구, 관악구 등)**를 선택합니다.
* **서비스 출력:** 1. 머신러닝 회귀 모델이 예측한 다음 달 구체적 사고 수치를 바탕으로, 임계치에 따라 연동된 **단기 전세 위험 등급(🚨상 / ⚠️중 / ✅하)**을 화면 최상단에 직관적인 배너로 노출합니다.
  2. `Plotly` 그래프를 통해 해당 구의 지난 1년간 전세가율 추이와 보증사고 증가 흐름을 동적으로 매칭하여 보여줍니다.
  3. `Folium Choropleth` 지도를 화면 중앙에 표출하여 서울시 전체 25개 구 중 현재 어느 지역이 가장 위험한지 시각적 격차를 제공합니다.

### 3.2 핵심 알고리즘 (하이브리드 모델링)
* 정보 손실을 방지하기 위해 **Scikit-learn의 `RandomForestRegressor`**를 사용하여 연속형 숫자로 정밀하게 학습을 진행합니다.
* 학습된 모델이 도출한 예측값(수치)을 대시보드 출력 직전 단계에서 **'상/중/하' 범주형 등급으로 맵핑**하여 사용자 친화적인 인터페이스를 완성합니다.

## 4. 예상 난관 및 해결책

* **예상 난관 1: 데이터 해상도 및 시차 정합성 문제**
  * *내용:* 수치 데이터와 정답지의 시간축이 꼬이거나 공간 단위를 서울시 전체로 뭉뚱그리면 예측 신뢰도가 붕괴되는 문제
  * *해결책:* 분석 범위를 최신 이동 윈도우(`2025.05 ~ 2026.04`)로 고정하고, 임대차시장 사이렌을 통해 확보한 **'진짜 자치구별 월별 실제 데이터'**를 매칭합니다. 판다스의 `.shift(-1)`를 통해 인과관계 시차(Time-lag)를 정당하게 부여함으로써 학술적 정합성을 확보합니다.
* **예상 난관 2: Streamlit 멀티페이지 구동 시 데이터 반복 로딩으로 인한 성능 저하**
  * *내용:* 화면 전환이나 자치구 변경 시 원천 CSV 파일을 계속 다시 읽어와 웹 앱이 멈추거나 느려지는 현상
  * *해결책:* `src/data_loader.py`에 데이터 파이프라인을 독립시킨 후 상단에 **`@st.cache_data` 데코레이터를 필수 적용**하여 최초 1회만 메모리에 적재 후 캐싱 데이터를 재활용하도록 최적화합니다.

## 5. 핵심 목표 및 기대효과 (MVP 개발 가이드라인)

* **`1_EDA.py` (데이터 정제):** 서울시 부동산정보광장의 실거래 전세가율과 임대차시장 사이렌의 보증사고 데이터를 `['년월', '자치구']` 키를 기준으로 완벽하게 `pd.merge()`하여 학습용 패널 데이터 마스터 테이블 구축
* **`2_시각화.py` (인사이트 도출):** `Plotly` 인터랙티브 라인/스캐터 차트를 구현하여 특정 자치구의 전세가율 상승이 1~2달 뒤 실제 보증사고 건수 증가로 이어지는 시차 상관관계를 시각적으로 증명
* **`3_모델_서비스.py` (예측 대시보드):** `RandomForestRegressor` 기반 회귀 모델의 예측값에 기반한 위험도 산출 알고리즘 연동, `streamlit-folium`을 활용한 서울시 자치구별 위험 등급 격자 지도(Choropleth map) 시각화 최종 구현
