# 📄 빅데이터 프로젝트 계획서

## 1. 프로젝트 주제
### **공공 임대차 데이터 기반 서울시 자치구별 전세 보증사고 위험 등급 예측 대시보드**

> 전세 사기 및 깡통전세 문제를 서울시 25개 자치구의 연립·다세대 주택 전세가율과 HUG 보증사고 데이터를 결합하여 분석합니다. 현재 시점($t$)의 전세 시장 지표로 다음 달($t+1$)의 보증사고 위험 등급(상/중/하)을 예측하는 Streamlit 기반 멀티페이지 대시보드를 구축합니다.

---

## 2. 프로젝트 문제 정의

### 2.1 선택한 데이터셋
* **한국부동산원 임대차시장 사이렌 월별 데이터**
  * **출처(URL):** https://www.rtech.or.kr/portal/rental/rentalMarket.do
  * **형식 및 크기:** Excel 형식, 월별 파일 46개 (2022년 8월 ~ 2026년 5월)
  * **분석 대상:** 서울시 25개 자치구 × 46개월
  * **주요 변수:** `자치구`, `년월`, `전세가율(%)`, `전세가율_3개월(%)`, `보증사고건수`, `보증사고금액`, `보증사고율(%)`

### 2.2 풀고 싶은 문제
* **핵심 목표:** 현재 달($t$)의 전세 시장 지표로 **다음 달($t+1$)의 자치구별 보증사고 위험 등급**을 선제적으로 예측하고 시각화합니다.
* **예측 대상 (Target):** $t+1$ 시점의 보증사고건수를 3분위 기준으로 분류한 위험 등급 (상/중/하)
* **시차 설계:** `df.groupby('자치구')['보증사고건수'].shift(-1)` 으로 인과관계 시차 부여

### 2.3 왜 분류(Classification)인가
연속형 수치 예측(Regression)은 샘플 수가 적을 때 노이즈에 취약합니다. 상/중/하 3등급으로 구간화하면 일시적 수치 변동을 흡수하여 안정적인 예측이 가능하고, 사용자에게 직관적인 결과를 제공할 수 있습니다.

## 3. 만들 서비스 (완성 모습)

### 3.1 화면 구성 (4개 페이지)

| 화면 | 주요 내용 |
| :--- | :--- |
| 🏠 메인 화면 | 서울시 전체 보증사고 현황 KPI, 자치구별 전세가율 막대 차트, 월별 사고 추이 |
| 🎯 기본 데이터 분석 | 위험 자치구 Top 5 랭킹, 자치구별 시계열 추이, 최악의 시점 기록 |
| 📊 실거래가 정밀 분석 | 피어슨 상관분석, t-검정, 시차 분석으로 전세가율↔보증사고 인과관계 통계 입증 |
| 🤖 모델 서비스 | 랜덤 포레스트 성능 및 혼동 행렬, 자치구 선택 → 다음 달 위험 등급 예측 및 실제 비교 |

### 3.2 핵심 알고리즘
* **RandomForestClassifier** (Scikit-learn) 로 $t+1$ 위험 등급(상/중/하) 분류
* 시간 기반 Train/Test 분리 (마지막 3개월 = Test) 로 미래 예측 구조 유지
* 입력 피처: 전세가율, 전세가율 변화율(전월 대비), 3개월 이동평균, 가속도, 보증사고건수

## 5. 예상 난관 및 해결책

* **난관 1: 최신 월 데이터 결측**
  * 데이터 집계 시점 특성상 최신 달 전세가율이 NaN으로 수집되는 문제
  * 해결: 자치구별 인접 월 선형 보간(interpolation) 적용

* **난관 2: 타깃 클래스 불균형**
  * 보증사고가 특정 자치구에 집중되어 상/중/하 불균형 발생 가능
  * 해결: `class_weight="balanced"` 적용으로 소수 클래스 가중치 보정

* **난관 3: 멀티페이지 성능 저하**
  * 화면 전환 시마다 데이터를 반복 로딩하여 앱이 느려지는 현상
  * 해결: `src/utils.py`에 `@st.cache_data` 적용으로 최초 1회만 로딩 후 캐싱

## 6. 사용 기술 스택

| 단계 | 적용 기술 | 활용 내용 |
| :--- | :--- | :--- |
| **웹 프레임워크** | Streamlit | 멀티페이지 애플리케이션 구현 |

| **시각화** | Plotly | 시계열, 산점도, 혼동 행렬 등 인터랙티브 차트 |
| **머신러닝** | Scikit-learn | RandomForestClassifier (t+1 위험 등급 분류) |
