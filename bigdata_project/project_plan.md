# 빅데이터 프로젝트 계획서 (수정본)

## 프로젝트 주제

공공데이터 기반 서울시 구별 전세 사기 위험도 지수 산출 및 위험 구역 예측
 
> 최근 사회적 문제로 대두된 전세 사기를 공공데이터(CSV)로 분석하여,
> 서울시 행정구별 임차인 위험도 지수를 산출하고 GIS 시각화를 통해 위험 지역을 직관적으로 표현하는 초압축형 프로젝트
 
---

## 데이터 (수집 방식 변경: API → CSV 통계 데이터)

### 1. 한국부동산원 — 행정구역별 전세가율 현황 (KOSIS / 공공데이터포털)
- **출처:** 국가통계포털(KOSIS) 또는 공공데이터포털
- **활용:** 서울시 25개 구별 월별/분기별 전세가율($\text{전세가} \div \text{매매가}$) 추출 → 데이터 정제 및 결합의 핵심 변수
- **형식:** CSV 파일 (다운로드 후 즉시 활용)

### 2. 주택도시보증공사(HUG) — 전세보증금 반환보증 사고현황 (지역별)
- **출처:** 공공데이터포털
- **활용:** 서울시 구별 보증 발급건수 및 사고율 추출 → 위험도 지수 산출 및 회귀 모델의 주요 독립변수(X)로 활용
- **형식:** CSV 파일 (기존 계획 데이터 유지)

---
 
## 핵심 목표
서울시 25개 구를 대상으로 **전세가율과 보증사고율을 결합한 행정구별 임차인 위험도 지수**를 개발하고, **회귀 분석(XGBoost)**을 통해 위험 요인을 파악 및 예측하며, 이를 **Folium 지도**로 시각화한다.
 
## 분석 흐름 (2주 완성형 Agile 프로세스)
 
1. **데이터 수집 및 병합 (1~2일차)**
   - Open API 호출을 전면 배제하고, 가공된 CSV 파일 다운로드로 대체하여 수집 시간 최소화
   - 서울시 25개 구(‘강서구’, ‘화곡동’ 등 행정구역 매칭)를 기준으로 두 데이터를 `pd.merge()`하여 단일 데이터프레임 구축
2. **위험도 지수(Index) 산출 (3~4일차)**
   - 거시적 위험도를 직관적으로 판단할 수 있는 가중합산 공식 적용
   - $\text{위험도 지수} = (\text{전세가율} \times 0.6) + (\text{보증사고율} \times 0.4)$ (가중치는 분석 과정에서 조정 가능)
   - 지수 점수를 바탕으로 각 구별 위험 등급(상/중/하) 분류
3. **탐색적 데이터 분석 (EDA) (5~7일차)**
   - 서울시 25개 구별 위험도 지수 분포 파악 및 랭킹 산출
   - 전세가율이 80%를 초과하는 ‘깡통전세’ 위험 구역 집중 분석
4. **회귀 모델링 (XGBoost) (8 =10일차)**
   - **종속변수(Y):** 구별 전세 사기 위험도 지수 (또는 전세가율)
   - **독립변수(X):** HUG 보증사고 건수, 사고 금액, 지가 변동률, 구별 인구수 등 요약 통계 변수
   - **알고리즘:** XGBoost Regressor를 활용하여 위험도에 가장 큰 영향을 미치는 변수(Feature Importance)를 도출하고 단기 위험도 예측
5. **GIS 지도 시각화 (11~12일차)**
   - 서울시 구 단위 GeoJSON 행정구역 경계 데이터 활용
   - `folium.Choropleth`를 이용하여 위험 등급별로 구 색상을 다르게 표현 (예: 고위험 구역은 붉은색)
   - 마우스 오버/클릭 시 해당 구의 전세가율 및 사고율 세부 수치가 팝업으로 나타나도록 구현

## 사용 기술 스택
 
| 단계 | 기술 | 비고 |
| :--- | :--- | :--- |
| **데이터 수집** | pandas | API 무사용, 다운로드 기반 CSV 로드 |
| **전처리/지수화** | pandas, numpy | 구(District) 단위 텍스트 매칭 및 가중합 연산 |
| **시각화** | matplotlib, seaborn | 변수 간 상관관계 Heatmap 및 분포 시각화 |
| **머신러닝 모델링** | scikit-learn, xgboost | XGBoost 기반 회귀 분석 (변수 중요도 도출) |
| **지도 시각화** | Folium, GeoPandas | 서울시 구 단위 Choropleth 지도 구현 |
