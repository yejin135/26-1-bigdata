# 빅데이터 프로젝트 계획서
 
## 프로젝트 주제
 
공공데이터 기반 지역별 전세 사기 위험도 및 부동산 가격 변동성 예측
 
> 최근 사회적 문제로 대두된 전세 사기를 공공데이터로 분석하여,
> 지역별 임차인 위험도 지수를 산출하고 GIS 시각화로 위험 지역을 직관적으로 표현하는 프로젝트
 
---
### 데이터

### 1. 국토교통부 — 아파트 전월세 실거래가 (Open API)
 
- 출처: 공공데이터포털
- 링크: https://www.data.go.kr/data/15126474/openapi.do
- 활용: 지역별·주택유형별 전세가 추출 → 전세가율(전세가÷매매가) 계산의 핵심 재료
- 형식: REST API (JSON/XML), 법정동코드 + 계약년월 기준 월별 호출
### 2. 국토교통부 — 아파트 매매 실거래가 (Open API)
 
- 출처: 공공데이터포털
- 링크: https://www.data.go.kr/data/15126469/openapi.do
- 활용: 전세가율 계산을 위한 매매가 데이터, 연도별 가격 변동성 시계열 분석
- 형식: REST API (JSON/XML), 법정동코드 + 계약년월 기준 월별 호출
### 3. 주택도시보증공사(HUG) — 전세보증금반환보증 상세현황 (지역별)
 
- 출처: 공공데이터포털
- 링크: https://www.data.go.kr/data/15033824/fileData.do
- 활용: 시도별·주택유형별 보증 발급건수 및 사고율 추출 → 위험도 지수의 보조 지표로 활용
- 형식: CSV 파일 (2016년~현재, 17개 시도 × 주택유형별)
---
 
### 핵심 목표
 
전세가율과 보증사고율을 결합한 **지역별 임차인 위험도 지수**를 만들고,
이를 행정구 단위 지도로 시각화한다.
 
### 분석 흐름
 
1. **데이터 수집 및 병합**
   - 전월세 API + 매매 CSV → 동일 주소 기준으로 merge
   - 전세가율 = 전세가 ÷ 매매가 계산
2. **탐색적 데이터 분석 (EDA)**
   - 전세가율 80% 이상 지역 분포 파악
   - 주택유형별(아파트 vs 빌라·다세대) 위험 차이 비교
   - 연도별 전세가율 추이 시계열 시각화
3. **위험도 지수 산출**
   - 전세가율, 건축연도(노후도), 주택유형, HUG 사고율을 가중합산
   - 행정구 단위로 집계하여 위험 등급(상/중/하) 분류
4. **예측 모델링**
   - 과거 전세가율 데이터 기반 향후 변동 예측 (Prophet 또는 ARIMA)
   - 지역·건물 특성으로 전세가율 예측하는 회귀 모델 (XGBoost)
5. **GIS 시각화**
   - Folium choropleth 지도에 위험도 등급을 색상으로 표현
   - 고위험 지역 클릭 시 세부 통계 팝업 표시
### 사용 기술 스택
 
| 단계 | 기술 |
|------|------|
| 데이터 수집 | requests, pandas |
| 전처리 | pandas, numpy |
| 시각화 | matplotlib, seaborn |
| 모델링 | scikit-learn, xgboost, prophet |
| 지도 시각화 | Folium, GeoPandas |
